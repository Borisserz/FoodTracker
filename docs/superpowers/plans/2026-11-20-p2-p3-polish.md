# P2–P3 Polish, Reliability & Feature Completeness Plan

> **Goal:** Complete P2–P3 fixes across SwiftData persistence, core nutrition/fasting/meal-copying UX, AI & camera scanner reliability, HealthKit/LiveActivity/notifications/deep-links, Firestore security rules, widget configuration, localization, dead-code removal, and automated tests using TDD.

**Stack:** SwiftUI, SwiftData, ActivityKit, HealthKit, WidgetKit, Firebase Auth/RemoteConfig/Functions (Node 22), XCTest, Node test runner.

---

## Wave 1: SwiftData, Core Nutrition, Fasting & Meal Copying
1. **Schema & Persistence (`SharedModelContainer.swift`, `DataModels.swift`, `DailyXPQuestsCardView.swift`, `HomeDashboardView.swift`, `CreateRecipeView.swift`):**
   - Add explicit `VersionedSchema` (`FoodTrackerSchemaV1`) and `SchemaMigrationPlan` (`FoodTrackerMigrationPlan`) while keeping CloudKit/local fallback resilient.
   - Add `fiber: Double = 0.0` and `sugar: Double = 0.0` to `FoodItem` (plus `netCarbs` computed property, `Meal`/`DailySummary` totals, `NutritionMath.scaledValues` / `EditableFoodDraft`, OpenFoodFacts + FatSecret parsing in `NetworkManager.swift` & `functions/index.js`, and display in `FoodDetailNutritionView.swift` / `AddMealView.swift`).
   - Add sex/age-aware RDA helper `AnalyticsMicro.rda(for:)` (`iron`: 8 mg male / 18 mg female <=50 / 8 mg female >50; `vitaminD`: 15 mcg <=70 / 20 mcg >70), keeping static `.rda` compatible with existing tests.
   - Make `DailyNoteSheet` edit draft `@State` values and commit only on `Save`.
   - Call `context.save()` after `progressManager.syncLevel()` in `DailyXPQuestsCardView.swift`.
   - Insert newly created custom ingredient in `AddIngredientModalView.saveIngredient()` into `modelContext` and persist it.
   - Remove unnecessary weight scaling slider for Quick Entry items (`baseWeight <= 0`) in `AddMealView.FoodItemRowCard`.
   - Allow deleting individual `ActivityLog` items in `DailyLogDetailView` (with daily calorie recalculation / HealthKit cleanup).

2. **Fasting History, Start-Time Editing & Custom Duration (`FastingManager.swift`, `FastingDashboardView.swift`, `LocalDataResetService.swift`):**
   - Persist completed `FastingRecord` entries via `UserDefaults` (`fastingHistory`), expose `history`, `updateStartTime(_:)`, and `startCustomFast(hours:)`.
   - Add UI controls in `ActiveFastingCard` (edit start time sheet) and `FastingDashboardView` (custom duration picker + completed fasts history section).

3. **Meal & Day Copying (`DataModels.swift`, `HomeDashboardView.swift`):**
   - Add `DailySummary.copyMeal(from:toDate:targetSlot:in:)` and `DailySummary.copyDay(from:toDate:in:)` preserving macros, micros, fiber/sugar without copying HealthKit sample IDs.
   - Expose Copy Meal / Copy Day actions in `MealDetailView` and `DailyLogDetailView`.

4. **ViewModel & UI Bugfixes (`AnalyticsViewModel.swift`, `HomeDashboardView.swift`, `SmartPlanBuilderFlow.swift`, `WeeklyPlanOverview.swift`, `ShoppingListView.swift`, `ChefRecipesView.swift`, `WeightTrackerCardView.swift`):**
   - Cancel prior load `Task` in `AnalyticsViewModel.loadData` + refresh on day rollover/changes; keep `user.streakDays` synchronized with `NutritionMath.consecutiveStreak`.
   - Deduplicate manual additions in `ShoppingListView` and add dismiss toolbar button when presented as a sheet.
   - Make `calorieRanges` in `ChefRecipesView` non-overlapping (`0...299`, `300...449`, `450...599`, `600...5000`) and ensure favorite state reflects live updates in `FilteredRecipesListView`.
   - Stop instantiating `@Model FoodItem` inside computed `filteredLocalFoods` in `SmartAddFoodView` (`cachedRecipeFoods` updated safely).
   - Remove redundant double header/2s delay in `SmartPlanBuilderFlow` / `WeeklyPlanOverview`.
   - Default `WeightInputSheet` initial value to `user.weight` when `summary.weight == nil`.

## Wave 2: AI Flows, Camera Scanner, Network Scaling & SSE
1. **`AIAssistantFlowView` (`AIChefStudioView.swift`):** Add Save to My Recipes & Log to Diary actions in `AgentCookingView`; unify calorie budget constant (`400`) across UI & prompt.
2. **Scanner (`BarcodeScannerController.swift`, `SmartScannerView.swift`):** Guard `AVBarcodeScannerRepresentable.updateUIViewController` with `lastIsScanning`, serialize camera mode teardown/startup transitions, add capture timeout safeguard for `isCapturingPhoto`, ensure main-thread callbacks.
3. **AI Client & Service (`GeminiProxyClient.swift`, `AINutritionService.swift`):** Route `rateLimitAlertMessage` writes/reads safely on `@MainActor`, delimit user inputs cleanly in prompts, harden `DailyVerdictDTO` decoding & error surfacing.
4. **`AICoachDashboardView.swift`:** Estimate micros in `logSuggestedSnack`, schedule actual local reminder notification in `HydrationFixResultSheet`, avoid wiping `hasAnalyzedToday` on snack log.

## Wave 3: HealthKit, Live Activities, Notifications, Deep Links & Auth
1. **HealthKit & Weight Timestamp (`WeightTrackerCardView.swift`, `AppleHealthSettingsView`, `ReusableComponents.swift`):** Use current time-of-day when logging today's weight; trigger re-sync when HealthKit is enabled; clarify `BurnedDetailsCard` labels and totals.

3. **`ReminderNotificationScheduler` (`ProfileView.swift`):** Serialize concurrent `sync` / `syncOnAppActive` calls via actor coordinator; show denied notification warning + Settings button; align copy with actual schedule.
4. **Deep Links, Auth, RemoteConfig & ShareSheet (`FoodTrackerApp.swift`, `ShareSheetManager.swift`, `SocialAuthService.swift`, `RemoteConfigManager.swift`):** Move `onOpenURL` handling to root `WindowGroup` with pending route queue; scroll to metabolic section for `foodtracker://metabolic`; select `.foregroundActive` window scene in `ShareSheetManager`; delete empty orphan anonymous Firebase account before switching on `.credentialAlreadyInUse`; coalesce concurrent `RemoteConfigManager.fetchCloudValues()` calls and set defaults.
